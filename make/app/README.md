Perpetuus CRM
=============

Official Make app for [Perpetuus CRM](https://perpetuus.com.br): watch new cards, cards entering a phase,
new contacts and completed tasks; create or update contacts; create, move and tag cards; create tasks;
search contacts and cards; and call any other Perpetuus API endpoint.

Connect with a Perpetuus API key (`ppt_…`). In Perpetuus, go to **Settings → API Tokens e MCP →
Conectar sua IA (MCP) → Conectar editor → Conectar novo editor**, choose the validity (1 to 365 days)
and the `crm:write` scope (it includes `crm:read`). "Watch new messages" also needs `chat:read`
(or `chat:write`, which includes it). The key is shown only once.

API documentation: https://docs.perpetuus.com.br/docs/api
